6. Acceptance Criteria Assessment

The evaluation gate implements an absolute ROC-AUC threshold.
It also supports comparison against an explicitly supplied
incumbent score.

The managed pipeline uses the absolute threshold as its
automatic registration criterion.

Registration and staging deployment are contained inside a
compiled KFP conditional branch requiring decision == pass.

Limitations:
- The managed pipeline does not automatically fetch the
  incumbent metric from Vertex AI Model Registry.
- The weak-candidate and incumbent tests were executed
  locally, not as Vertex AI Pipeline runs.
- A real managed pipeline execution with a failing gate
  and skipped registration has not been demonstrated.

The evidence supports a working metric-threshold gate and
a correctly compiled registration condition. It does not
claim that every possible production regression is blocked.
